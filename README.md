# `gfold-py` ***`neo`***
A fresh ***neo*** implementation of G-FOLD (**G**uidance algorithm for **F**uel **O**ptimal **L**arge **D**iverts) algorithm in `python` with `cvxpy`.

This is a fresh new start of the original project `gfold-py`(2022-2024).
